# DESIGN.md library

Source: github.com/VoltAgent/awesome-design-md at `fcc7028`, MIT. Files live in `~/.claude/skills/design-md/library/design-md/<site>/DESIGN.md`.

1. List the choices: `ls ~/.claude/skills/design-md/library/design-md/`. The library README's Collection section has a one-line summary of each.
2. Pick one that fits the direction from `design-taste-frontend`, or the site the person named. Taste decides the direction; DESIGN.md supplies the tokens.
3. Copy it to the project root as `DESIGN.md`, then build from its tokens (`{colors.primary}` and similar) and its Do's and Don'ts.
4. Each file is an interpretation of a real brand's style. Use the tokens and rules, never its logo, name, wording or imagery, and change the palette or type enough that the result reads as the project's own.

If the project already has a DESIGN.md, follow it instead.
